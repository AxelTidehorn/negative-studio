# FILMLABB 1.1 Beta 3.3

Förhandsvisningen reagerar snabbare på reglagen. Filmrutekorrigering, tidigare projekt, RAW, färgformler och export är oförändrade. Lägg hela ZIP-innehållet i befintlig GitHub-root och bevara .github/workflows. Kör npm ci, npm test och npm run build; publicera site/ som tidigare. Inga nya beroenden. Den befintliga Actions-workflowfilen fanns inte i underlaget och ersätts inte.

Kontrollera 1.1 Beta 3.3 i sidfoten efter omladdning. Cachen är uppdaterad, och slider-response.js måste vara publicerad i site/. Se docs/PRESTANDA_BETA3_3.md för begränsningar. Ingen fysisk Edge/Chrome- eller iPad-mätning har gjorts här.
