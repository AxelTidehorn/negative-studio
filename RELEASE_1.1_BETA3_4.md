# FILMLABB 1.1 Beta 3.4

Mobil arbetsyta med kvarvarande bild över rullningsbara reglage och horisontell bildkö på telefon. Bildmotor, export, manuella filmrutor, RAW, projekt och desktoplayout är bevarade.

Lägg hela ZIP-innehållet i befintlig GitHub-root; bevara .github/workflows. Kör npm ci, npm test, npm run build och publicera site/ som tidigare. Ingen ny dependency. Den befintliga workflowfilen saknades i underlaget och ersätts inte. Kontrollera 1.1 Beta 3.4 i sidfoten; mobile-layout.css måste ingå i site/ och offlinecache.
